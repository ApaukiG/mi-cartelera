Mi Cartelera Personal

Brand board · sistema de diseño de DESIGN.md

Representación visual del CSS propio de la app (src/index.css), sin Bootstrap. Lo marcado NUEVO es una propuesta para la épica E2 que todavía no existe en el código.

Principios visuales

  1. Sala de cine de noche. Fondo casi negro con destellos de luz difuminados.
  2. El póster es el protagonista. Formato 2:3; el resto de la interfaz es sobrio.
  3. Un solo acento cálido. El naranja marca la acción principal, el foco y el hover.
  4. Títulos con carácter, texto legible. Cinzel para títulos, fuente del sistema para el resto.
  5. Superficies discretas. Paneles oscuros, borde blanco al 10 %, esquinas suaves.
